# YUTORI EVENT ARCHIVE

ゆとり主催の Apex Legends カスタム大会の結果発表サイトです。GitHub Pages で公開しています（サーバー費用なし）。

公開URL: <https://yutori0718.github.io/yutori-event-archive/>

## サイト構成

- **Top** (`/`) : サイトのトップページ
- **Apexカスタム** (`/apex-custom/`) : 大会一覧。大会名をクリックすると結果発表ページへ
- **大会結果発表ページ** (`/apex-custom/detail.html?id=...`) : マップ進行・最終順位（1〜3位はカード、4位以降はリスト）を表示。チーム名をクリックすると、そのチームのパスワードを入力してチーム詳細（試合ごとの成績・メンバー個人のダメージ/キル）を開ける
- **出場履歴** (`/participation-history/`) : ゆとり自身が出場した大会の履歴

## 管理者ページ（大会結果の新規作成・編集）

サイト上の管理者ページから、大会の新規作成・編集ができます。ローカルツールやPCソフトは不要です。

管理者ページURL: <https://yutori0718.github.io/yutori-event-archive/admin/>

### ログイン方法（メールアドレス＋パスワード）

管理者ページへのログインは、メールアドレス（`yutoridesuga.30@gmail.com`固定）とパスワードで行います。

ただし実際にサイトを更新するにはGitHubへの書き込み権限が必要なので、**初めてログインする端末・ブラウザでは最初に一度だけ**GitHubのPersonal Access Tokenの入力が必要です（下記「初回の初期設定」）。入力したトークンは、その場で設定するパスワードを使って暗号化され、この端末のブラウザだけに保存されます（平文のまま保存されることはありません）。以降はその端末では、メールアドレスとパスワードだけでログインできます。

> ⚠️ この保管は「端末＋ブラウザ」ごとです。別のPCやスマホ、別のブラウザから使う場合は、そちらでもう一度だけ初期設定（トークンの入力）が必要です。ログイン画面から「初期設定からやり直す」を選ぶと、パスワードを忘れた場合も新しく設定し直せます（この端末に保存されていたトークンは消え、再度トークンの入力が必要になります）。

#### 初回の初期設定（端末ごとに一度だけ）

1. GitHubで右上のアイコン → **Settings** → 左メニュー最下部 **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. `Repository access` で **Only select repositories** → `yutori-event-archive` を選択
4. `Permissions` → `Repository permissions` → **Contents** を **Read and write** に設定（他は変更不要）
5. 有効期限はお好みで（90日など）。発行されたトークン（`github_pat_...`）をコピー
6. 管理者ページの初期設定画面で、メールアドレス（自動入力済み）・好きなパスワード（2回）・上記トークンを入力して設定

### 使い方

1. 管理者ページを開き、メールアドレスとパスワードでログイン（初回はまず上記の初期設定）
2. 「＋ 新規大会を作成」または一覧から「編集」
3. 大会名・開催日時・ルール・ステータスを入力
4. マップ（試合）を大会ごとに自由な数だけ追加・削除できます。試合が終わったら「終了済み」にチェック
5. チームを追加し、最終順位・合計ポイントを入力（これらは誰でも見られる公開情報）
6. 同じチーム欄で「マッチpt・ランクボーナス・最高順位・試合ごとの成績・メンバー3名の試合ごとのダメージ/キル」を入力（これらはチームのパスワードで保護される非公開情報）
7. 「保存してサイトに反映」で、GitHub上のデータファイルへ直接コミットされます（数十秒〜数分でサイトに反映）

新規チーム作成時は自動でパスワードが発行されます（「再生成」で作り直しも可能）。公開ページでチーム詳細を見る人に共有する用のパスワードなので、大会関係者に伝えてください。（このチームごとのパスワードは、上記の管理者ログイン用パスワードとは別物です）

## チーム詳細のパスワード保護について

チーム詳細（試合ごとの成績・メンバー個人成績）は、ブラウザ内で **AES-GCM暗号化** されたうえでデータファイルに保存されます。パスワードから鍵を作って復号する方式なので、サーバーを用意しなくても本当にパスワードを知らないと中身を読めません（見た目を隠しているだけではありません）。

- 最終順位（チーム名・順位・合計ポイントのみ）は誰でも見られます
- 公開ページでチーム詳細を開くには、そのチームのパスワードの入力が必要です
- パスワードはチームごとに別々に発行できます
- **管理者ページを使うこの端末では、チームごとのパスワードは自動で記憶されます。** 一度保存したチームを後日また編集するときも、パスワードを入力し直す必要はありません（試合結果を大会当日に少しずつ追加していく、といった使い方も問題ありません）。何度編集・保存を繰り返してもデータは消えません
- この自動記憶は「この端末のこのブラウザ」限定です。別の端末で編集する場合は、その端末でそのチームのパスワードを一度だけ入力してロック解除してください
- パスワードを忘れて別の端末でも分からなくなった場合は、チームごとの「⚠️ パスワードが分からない場合はここから作り直す」から新しいパスワードを発行できますが、その場合は古い試合結果・個人成績データは復元できず、そのチームのデータは白紙から入力し直しになります（間違って押さないよう、ボタンは目立たない場所に置いています）

### チーム詳細（復号後）の中身

パスワードを解いた後にチームごとに見える内容は次の形です。メンバーの個人成績は試合ごとに入力し、公開ページ側で合計・命中率・ヘッドショット率を自動計算します。

```jsonc
{
  "matchPoint": 61,
  "rankBonus": 0,
  "bestPlace": 1,
  "matchResults": [{ "match": 1, "teamRank": 1, "teamPoint": 15, "teamKills": 8 }],
  "members": [
    {
      "name": "メンバー1",
      "statsByMatch": [
        {
          "kills": 3, "damage": 320, "assists": 1, "knockdowns": 2,
          "revives": 1, "respawns": 0, "shots": 40, "hits": 22,
          "headshots": 6, "survivalTime": 720
        }
      ]
    }
  ]
}
```

- `survivalTime` は秒数で入力します（公開ページで分:秒に整形して表示）
- 命中率(Acc%) = 合計命中数 ÷ 合計ショット数 × 100
- ヘッドショット率(HSR%) = 合計ヘッドショット数 ÷ 合計ショット数 × 100
- この2つは試合ごとではなく、合計欄にのみ表示されます

## データファイル

```text
data/apex-custom.json          Apexカスタム大会（通常はJSONを直接触らず管理者ページから編集）
data/participation-history.json  出場履歴（変更なし）
```
